Project

CI/CD pipeline: GitHub to AWS with Docker and Kubernetes

This page is the app. Every push to GitHub triggers a pipeline that builds a Docker image of this site, pushes it to Amazon ECR, and deploys it to AWS with no manual steps. I built it in six phases, starting simple on EC2 and ending on Kubernetes.

  1. Portfolio site + DockerfileSite runs in a container locally
  2. GitHub Actions CIEvery push builds and tests the image
  3. Push image to Amazon ECRVersioned images stored in AWS
  4. Deploy to EC2 with DockerLive site on a public IP
  5. CD: auto-deploy on pushPush code, site updates itself
  6. Upgrade to Kubernetes (k3s on EC2 or EKS)Self-healing, scalable deployment
